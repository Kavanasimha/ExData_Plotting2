# ExData_Plotting2

# Exploratory Data Analysis – Course Project 2

This repository contains six R scripts and six corresponding PNG plots analysing PM2.5 emissions from the US National Emissions Inventory (NEI) for 1999, 2002, 2005, and 2008.

## Instructions

Place `summarySCC_PM25.rds` and `Source_Classification_Code.rds` in the working directory before running the corresponding R scripts.

Each `plotN.R` script generates its corresponding `plotN.png` visualization.
